# Politique de sécurité

## Données sensibles

Ne jamais publier dans ce dépôt :

- mots de passe ;
- clés API, tokens ou cookies ;
- fichiers `.env` ;
- credentials n8n ;
- données réelles de clients ;
- exports de bases contenant des données personnelles.

Les exemples doivent être fictifs ou anonymisés. Les profils de navigateur Playwright sont exclus de Git car ils peuvent contenir des sessions connectées.

## Signalement

Pour signaler un secret publié ou une vulnérabilité, ne pas ouvrir d’issue publique. Prévenir directement le propriétaire du dépôt et révoquer immédiatement le secret concerné.

## Limites

Les contrôles automatisés réduisent les erreurs mais ne remplacent pas une revue humaine, une gestion des accès, des sauvegardes et une validation juridique ou RGPD adaptée au contexte.
